# Fishing Adventure

A small mobile-friendly fishing game made with HTML, CSS, and JavaScript.

## Play locally
Open `index.html` in a modern browser.

## Controls
- **A / SWIM**: fish swim in random directions for 3 seconds.
- **B / FISH**: lower the hook to the seabed and bring it back.
- Each caught fish gives 1 point. Caught fish are replaced so 10 fish remain in the sea.

## Publish with GitHub Pages
1. Create a new repository on GitHub (for example, `fishing-adventure`).
2. Upload `index.html` and `README.md` to the repository's root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/(root)`, then save.
6. Wait for GitHub Pages to publish. Your game link will look like `https://YOUR-USERNAME.github.io/fishing-adventure/`.

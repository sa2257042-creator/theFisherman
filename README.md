# Fishing Adventure

A mobile-friendly fishing game made with HTML, CSS, and JavaScript.

## Files
- `index.html` — page structure
- `style.css` — appearance and responsive layout
- `game.js` — fish movement, hook, catches, and score

Keep all three files in the same folder.

## Controls
- **A / SWIM**: fish swim in random directions for 3 seconds.
- **B / FISH**: lower the hook to the seabed and bring it back.
- Each caught fish gives 1 point. Caught fish are replaced so 10 fish remain in the sea.

## Publish with GitHub Pages
1. Upload `index.html`, `style.css`, `game.js`, and `README.md` to the repository root.
2. Open **Settings → Pages**.
3. Under Build and deployment, choose Deploy from a branch.
4. Select the `main` branch and `/(root)`, then save.
